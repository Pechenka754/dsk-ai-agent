AI-агент для автоматизированного подбора квартир в жилых комплексах ГК «ДСК».

Агент понимает запросы пользователя на естественном языке, уточняет недостающие параметры, подбирает квартиры, позволяет выбирать и сравнивать ЖК и квартиры, получать дополнительную информацию и бронировать подходящие варианты.

Возможности:
1. поиск квартир по параметрам: количество комнат, цена, площадь, этаж;
2. уточнение недостающих параметров;
3. изменение параметров поиска в ходе диалога;
4. поиск ближайших альтернатив;
5. подбор и выбор жилых комплексов;
6. сравнение ЖК;
7. выбор и сравнение квартир;
8. получение информации о квартирах и ЖК;
9. рекомендации наиболее подходящих вариантов;
10. бронирование квартиры на 3 часа бесплатно или на 1 месяц за 20 000 ₽;
11. автоматическое освобождение квартиры после окончания бронирования;
12. передача запроса менеджеру;
13. сохранение контекста диалога в рамках пользовательской сессии.

Архитектура:

Пользователь
     ↓
Frontend
     ↓
FastAPI
     ↓
ApartmentAgent
     ├── GigaChat
     └── SQLite

Основная логика агента находится в agent.py.

Данные:
В проекте используется SQLite-база данных с информацией о жилых комплексах и квартирах. При пустой базе проект автоматически заполняет её тестовыми данными.

Структура проекта:
agent.py - основная логика AI-агента
api.py - FastAPI и API-эндпоинты
ai_parser.py - работа с GigaChat и обработка запросов
database.py - работа с SQLite
images/ - изображения квартир и ЖК
requirements.txt - зависимости проекта
.env.example - шаблон переменных окружения
russian_trusted_root_ca_pem.crt - сертификат для подключения к GigaChat

Требования:
Python 3.14 или совместимая версия;
GigaChat credentials.

Установка:
1. Клонирование репозитория
git clone <ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ>
cd dsk_ai_agent
2. Создание виртуального окружения
Windows:
python -m venv .venv
.venv\Scripts\activate
3. Установка зависимостей
pip install -r requirements.txt
4. Настройка GigaChat:
4.1 Создайте в корне проекта файл .env.
4.2 Используйте .env.example как шаблон:
GIGACHAT_CREDENTIALS=ваши_credentials

Для запуска проекта каждому разработчику необходимы собственные GigaChat credentials.

5. Сертификат (Файл russian_trusted_root_ca_pem.crt уже находится в корне проекта. Дополнительная установка сертификата не требуется)

Запуск:
1. Активируйте виртуальное окружение:
.venv\Scripts\activate

2. Запустите API:
uvicorn api:app --reload

3. После запуска API доступно локально.
Swagger:
http://127.0.0.1:8000/docs
API
GET /health

Проверка работоспособности backend.
Ответ:
{
  "status": "ok"
}
POST /chat

Основной endpoint для взаимодействия с агентом.
Запрос:

{
  "session_id": "user-123",
  "message": "Покажи двушки до 15 миллионов"
}

session_id должен оставаться одинаковым в рамках одного диалога пользователя.

Типы ответов:
Frontend определяет тип отображаемого результата по полю type.
search - результаты поиска
alternative - альтернативные варианты
clarification - уточняющий вопрос
selection - выбор квартиры или ЖК
information - информация о квартире или ЖК
comparison - сравнение квартир или ЖК
booking - бронирование
payment	- демонстрационный этап оплаты
manager	- передача запроса менеджеру
error - ошибка

Frontend не реализует логику поиска, определения намерения или работы с базой данных. Эти задачи выполняет backend.

Бронирование
В проекте реализовано демонстрационное бронирование:
бесплатное — 3 часа, 0 ₽;
длительное — 1 месяц, 20 000 ₽.

Оплата является демонстрационной и не подключена к реальному платёжному сервису.
После окончания срока бронирования квартира автоматически становится доступной.

Изображения
Изображения квартир и ЖК находятся в папке images/.
API возвращает пути к изображениям в соответствующих объектах ответа.
